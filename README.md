# The Long Roast: Lawmakers — entry

A program/v1 entry for the make.fun "The Long Roast"
bounty. `main.py` writes one satirical sentence to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The sentence:

> The amendment to ban deepfakes was itself submitted as a photo of a screen, taken at an angle, in Word.

The satire is in the artefact: a law about synthetic media,
filed in the one format that proves the filer has never met
a PDF. See `CANDIDATES.md` for the full draft list this
winner was picked from.
